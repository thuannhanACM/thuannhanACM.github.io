# Portfolio Site

A single-page personal portfolio for thuannhanACM, hosted on GitHub Pages. It presents personal information and a curated set of work, split into two distinct categories.

## Language

**Project**:
A finished, real-world piece of work worth showcasing in depth. Rendered as a large foldable card (expands on click to reveal role, tech stack, highlights, and links).
_Avoid_: Work, portfolio item, app

**Prototype**:
A smaller, less-finished experiment, proof-of-concept, or mini-app — distinguished from a Project by lower completeness and exploratory intent, not by whether it runs. Rendered compactly, not foldable.
_Avoid_: Demo, experiment, POC

**Others**:
The on-page section that lists all Prototypes as a compact grid. The user-facing heading for the Prototype collection.
